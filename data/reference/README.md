## Provenance Classification & Methodological Rules

> ### ⚠️ STRICT METHODOLOGICAL GOVERNANCE
> - **Provenance Status:** `INFERRED REFERENCE`
> - **Zero Empirical Evidence:** These records are **NOT real-world observations** and have not been verified against live postings.
> - **Permitted Use Cases:**
>   - Schema development and relational structure validation
>   - Terminology and title alias discovery
>   - Normalization rule design and regex testing
>   - Data cleaning pipeline development
> - **Prohibited Use Cases:**
>   - These records must **NEVER** be cited, aggregated, or presented as empirical evidence of the Sri Lankan IT labour market.
